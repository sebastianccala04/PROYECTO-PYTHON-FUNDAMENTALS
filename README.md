# Proyecto Python Fundamentals

Aplicación desarrollada en Streamlit para el Módulo 1 – Python Fundamentals.

## Archivos principales

- `app.py`: aplicación principal.
- `libreria_funciones_proyecto1.py`: librería de funciones.
- `libreria_clases_proyecto1.py`: librería de clases.
- `requirements.txt`: dependencias para Streamlit Cloud.

## Ejecución local

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Secciones

1. Home
2. Ejercicio 1 – Flujo de caja con listas
3. Ejercicio 2 – NumPy, arrays y DataFrame
4. Ejercicio 3 – Función externa de depreciación
5. Ejercicio 4 – Clase externa `InventarioProducto` con CRUD
